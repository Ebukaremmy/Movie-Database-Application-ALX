# Movie Finder App 🎬

A dynamic web application built with **React** and **Tailwind CSS** that allows users to search for movies in real-time using the **OMDb API**.

## 🚀 Features
- **Live Search:** Fetch movie data (titles, years, and posters) from a global database.
- **Responsive Grid:** A clean, mobile-friendly layout built with Tailwind CSS.
- **Dynamic UI:** Real-time state management for loading indicators and search results.
- **Error Handling:** Graceful handling of "Movie Not Found" and API errors.

## 🛠️ Tech Stack
- **Frontend:** React.js (Vite)
- **Styling:** Tailwind CSS v4
- **API:** OMDb (The Open Movie Database)
